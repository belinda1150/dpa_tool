**Naming Convention:**
- Data_Breach_Response_Plan_v1.0.pdf

## Common Fields Explained

**Policy Title:**
- Official name of the document
- Use exact mandatory document names for compliance
- Keep consistent for easy tracking

**Policy Type:**
- Dropdown selection
- Groups policies by category
- Helps with filtering and reporting

**Version:**
- Start with "1.0" for new policies
- Increment for major changes (1.0 → 2.0)
- Minor updates: (1.0 → 1.1)

**Description:**
- Brief summary (1-3 sentences)
- Explains purpose and scope
- Visible in policy list

**Status:**
- **Draft:** Work in progress, not visible to staff
- **Published:** Active, visible to all, requires acknowledgement
- **Archived:** Old version, read-only

**Review Due Date:**
- Set to 12 months from today
- System alerts when review is due
- Best practice: Annual review

## Troubleshooting

**Issue:** File upload fails
- **Solution:** Check file size (<10MB), Check file type (PDF/DOC/DOCX/TXT)

**Issue:** Can't access Policy module
- **Solution:** Requires Admin or DPO role. Contact administrator.

**Issue:** Policy not visible after upload
- **Solution:** Check Status is set to "Published", not "Draft"

**Issue:** Staff not receiving acknowledgement notifications
- **Solution:** Verify Status = "Published", Check user email addresses

**Issue:** Can't edit uploaded policy
- **Solution:** Click Edit button (pencil icon) on policy row
